# Asterline Desktop 0.1.0

The first Asterline graphical desktop preview keeps the existing local-first
runtime and adds an IDE-style workbench for the daily collaboration loop.

## Highlights

- Open and revisit project workspaces without changing the existing CLI/TUI.
- Stream team chat, member state, approvals, modes, Runs, and verification from
  the shared Asterline runtime.
- Restore local conversations and continue blocked or failed Runs.
- Edit complete team settings, including prompts, permissions, tools, modes,
  approval rules, session policy, and relay limits.
- Open provider sessions in an external terminal, with post-exit transcript
  import where Codex and Claude support it.
- English and Simplified Chinese UI, light and dark themes, keyboard-friendly
  navigation, and responsive layouts.
- Manual Desktop-only update checks and no telemetry.

Desktop 0.1.0 uses project state format `1` and is released independently from
the Asterline CLI under the `desktop-v*` tag series.
