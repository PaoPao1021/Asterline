# Asterline Desktop v0.2.0

Desktop V1.1 新增运行时日志、Git Diff、本地 Skills 和当前会话搜索四个只读工具抽屉。
工具请求均有边界并使用版本化桥接，因此大型工作区不会让运行时快照持续膨胀。

- 日志支持按级别、来源和文本筛选，单次最多返回 400 条。
- Diff 包含暂存、未暂存和未跟踪变更，输出上限 2 MiB，Git 命令超时为 10 秒。
- Skills 支持按后端和文本筛选，并可复制调用语法；不会向 WebView 暴露本地绝对路径。
- 查找支持匹配计数以及前后导航，范围限定为当前已加载聊天。

本版本保持 Desktop bridge 版本 `1`，不改变现有工作区锁、会话恢复、审批和团队设置行为。
