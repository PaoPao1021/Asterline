# Asterline Desktop

Platform: web (React in a Tauri WebView on Windows).

Users: developers coordinating local AI coding team sessions.
Primary job: open a workspace, send work to members, inspect replies and runs, and resolve approvals without losing context.

Existing capabilities must survive UI changes: sessions, imports/exports, composer modes and attachments, permissions, team settings, run controls, command palette, logs, diff, skills, update flow, Chinese/English and light/dark themes.

Approved visual direction: continuous mature developer workbench; neutral light/dark palettes with restrained Asterline green; subtly frosted left sidebar only; solid reading surfaces and crisp system typography. No decorative lettering, animated background, or text scaling effects. Generate a visual reference before each frontend development round.

This visual refactor does not claim new TUI feature parity or enable native Windows wallpaper transparency.
